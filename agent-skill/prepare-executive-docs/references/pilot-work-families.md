# Pilot work families

The workbook templates expose these pilot sheet candidates. This list is a mapping aid, not proof that every sheet applies to every project.

## KL-0.4 kV

Template `aosr_kl_04`, normally using `АОСР-3` and `АОСР-4`. Determine the exact work names, quantities, dates, materials, and scheme attachment from evidence. Do not infer that both acts are required merely because both sheets exist.

## KL-6 kV

Template `aosr_kl_6`, candidate sheets `АОСР-1` through `АОСР-7`. Preserve technological order established by the project and confirmed execution evidence.

## VRS

Template `aosr_vrs`, candidate sheets `АОСР-1` through `АОСР-6`. VRS means the relevant distribution switchboard family represented by the approved workbook. Do not use the separate facade-mounted VRS template in the MVP.

For every family, an unknown change state is blocking. If a change exists, an approved execution scheme is required. If no change exists, the project remains the governing design source and no scheme should be fabricated.
