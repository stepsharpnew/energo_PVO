# Workflow

The input is a project package used to prepare executive documentation. The output is a traceable AOSR package ready for specialist review, never a redesigned project.

Required phases:

1. Inventory and classify sources by content.
2. Extract the object card: object name and address, project code, organizations, selected branch, and source versions.
3. Extract proposed work items, actual dates, quantities, materials, and applications.
4. Store claims before deciding. Preserve both sides of every conflict.
5. Determine whether field conditions differ from the approved project: `YES`, `NO`, or `UNKNOWN`.
6. Ask one grouped NEEDS_INPUT batch for all known blockers.
7. After confirmed answers, rebuild facts and the work register from the saved state.
8. Build one document plan per supported workbook family.
9. Generate only through an approved template contract.
10. Validate, render each selected sheet, independently review, and send to the specialist.

The selected sheets define individual acts. The starting number belongs to the first selected act even if its original worksheet name is `АОСР-3`; subsequent selected acts receive consecutive numbers.

On retry, keep stable work IDs and already assigned AOSR numbers. On a requested revision, preserve the previous revision files and create a new revision.
