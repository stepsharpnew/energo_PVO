# Чек-лист ремонта двух пилотных шаблонов

Оригиналы находятся в `template/` и должны оставаться неизменными. Менеджер возвращает две отдельные исправленные книги: КЛ и ВРЩ. Нельзя удалять, переименовывать или переставлять листы.

## 1. `9. АОСР КЛ.xlsx`

### Повреждённые ячейки

На каждом листе ниже поле «Представитель лица, выполнившего работы» должно ссылаться на подтверждённые данные исполнителя. Предлагаемая логика для проверки менеджером:

- полная строка: должность `Данные объект!B19`, организация `B11`, ФИО `B20`, полномочия `B21` (эквивалент готовой строки `Данные объект!C21`);
- нижняя строка подписи: ФИО из `Данные объект!B20`.

| Лист | Полная строка, сейчас | Подпись, сейчас |
|---|---|---|
| АОСР-1 | `A53 = CONCATENATE(#REF!,...)` | `A114 = #REF!` |
| АОСР-2 | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |
| АОСР-3 | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |
| АОСР-4 | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |
| АОСР-5 | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |
| АОСР-6 | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |
| АОСР-7 | `A53 = CONCATENATE(#REF!,...)` | `A114 = #REF!` |
| АОСР-пожар | `A53 = CONCATENATE(#REF!,...)` | `A115 = #REF!` |

После подтверждения логики допустимы формулы:

```excel
='Данные объект'!C21
='Данные объект'!B20
```

Также удалить или восстановить именованный диапазон `кабель`, который сейчас указывает на `#REF!`. Если диапазон нигде не используется и не нужен, удалить его после проверки зависимостей.

### Старый объект

Очистить значения прошлого объекта в `Данные объект`: `B2:B7`, `B9`, `B43`. Ячейку `B44` оставить формулой `=B3`.

Сейчас среди старых значений присутствуют `SAP - 305042`, `Красный Воин`, `4609-305042-221-10/24`, `КЛ-10кВ ф.1 от ТП №3463` и даты 2025 года.

### Внешние связи

Заменить внешние формулы внутренними:

| Ячейка | Сейчас | Предлагаемая внутренняя ссылка |
|---|---|---|

После сохранения в книге не должно остаться ни одной внешней связи или запроса на обновление данных.

### Старый объект

Сейчас присутствуют `SAP - 301971`, `Жилино`, `3746-984421-20-02/23` и даты старого объекта.

## 3. Что не очищать без согласования

- названия, порядок и количество листов;
- объединения, стили, высоты строк и ширины столбцов;
- формулы, не указанные в этом чек-листе;
- печатные области и настройки страниц;
- справочник организаций и подписантов — сначала подтвердить актуальность, затем оставить либо обновить.

## 4. Проверка перед передачей

1. Поиск по всей книге: нет `#REF!`, `#VALUE!`, `#N/A`, `#DIV/0!`.
2. Excel не предлагает обновить внешние связи.
3. Книга сохраняется, закрывается и повторно открывается без восстановления.
4. Каждый лист АОСР корректно показывается в предварительном просмотре печати на A4.
5. Поля представителя и подписи заполняются после изменения `Данные объект!B19:B21`.
6. Поиск по книге не находит перечисленных старых SAP, адресов и шифров.
7. Менеджер сообщает ФИО проверившего и подтверждает, что данные организации/подписантов актуальны.
